Clothing Replacement Tracker

Project Description

The Clothing Replacement Tracker is a Java program that helps users keep track of their clothing and figure out when items may need to be replaced.

Features

Add new clothing items.

View clothing items saved in the program.

Update clothing information.

Remove clothing items.

Keep track of how many times each item has been worn.

Calculate the wear percentage using the number of wears divided by the expected wears, multiplied by 100.

Save clothing information in a text file so it can be loaded again.

Technologies Used

Java

Object-Oriented Programming

IntelliJ IDEA

Text file storage

How to Run

Run the ClothingReplacementTracker.jar file using Java from the command line.
